Getting started

Projection Lab is a folder of ES modules. There is no package to install and nothing to compile. This page walks from an empty folder to a lit, animated scene.

Setup

Copy three folders from public/ in the repository next to your page: engine/, shaders/ and vendor/ (which holds gl-matrix, used for model transforms). Keep them side by side; they import each other by relative path.

your-game/
index.html
main.js
engine/      the engine
shaders/     its GLSL, as JavaScript modules
vendor/      gl-matrix 3.4.4 (MIT)

Browsers only load modules over HTTP, so serve the folder with any static server. The repository ships one with no dependencies: node tools/serve.mjs.

If you would rather load one file, the site publishes the whole engine bundled and minified at dist/projection-lab.min.js (build it yourself with npm run build). It exports the same names as engine/index.js.

First scene

index.html
<canvas style="width:100vw;height:100vh;display:block"></canvas>
<script type="module" src="main.js"></script>
main.js
import { Game, Entity, Mesh, PBRMaterial, StandardMaterial, ShadowMap, primitives } from "./engine/index.js";

const game = new Game({ canvas: document.querySelector("canvas") });
game.scene.shadow = new ShadowMap({ extent: [8, 8] });

const floor = new Mesh(primitives.plane(20, 20), new StandardMaterial({ color: [0.8, 0.8, 0.85] }));
const gold = new Mesh(primitives.sphere(1, 48, 32), new PBRMaterial({ color: [1, 0.77, 0.34], metallic: 1, roughness: 0.25 }));

game.add(new Entity({ mesh: floor }));
const ball = game.add(new Entity({ mesh: gold }));
ball.setPosition(0, 0, 1.5);

game.onUpdate(() => ball.setYaw(game.time));
game.start();

That is this page. Game creates the renderer, a scene, an orbit camera, input and the loop. If WebGL is not available it shows a readable message instead of a blank canvas, and game.failed is true.

The world

  • Z is up. The ground is the XY plane. Models loaded from glTF (which is Y-up) are stood upright for you.
  • Units are yours. The examples treat one unit as a metre.
  • Colours are arrays of 0 to 1, such as [1, 0.5, 0.2]. Values above 1 are allowed and are what bloom picks up.
  • An Entity is a transform that can carry a mesh. Entities nest: parent.add(child). A Mesh is a geometry plus a material, and both can be shared between many entities.
const arm = game.add(new Entity({ mesh: new Mesh(primitives.box(0.3, 0.3, 2), steel) }));
arm.setPosition(4, 0, 1).setRotationEuler(0, 0.4, 0).setScale(1.5);
const hand = arm.add(new Entity({ mesh: new Mesh(primitives.sphere(0.3), steel) }));   // moves with the arm
hand.setPosition(0, 0, 1.2);
arm.onUpdate((dt, e) => e.setYaw(e.age));        // behaviour on the entity itself

The camera orbits a target at a distance, steered by yaw and pitch. Call camera.setFollow(entity) to trail something, or set camera.mode = "firstPerson" and move camera.position.

The loop

The simulation always advances in steps of exactly 1/60 s, whatever the screen's refresh rate, so gameplay is the same on every machine. Rendering happens once per screen refresh and blends between the last two steps, so motion stays smooth at 144 Hz.

RegisterRunsUse it for
game.onUpdate((dt) => …)every fixed stepgameplay, physics, reading input
game.onRender((frameDelta) => …)every drawn frameanimation playback, HUD text, camera feel
entity.onUpdate((dt, e) => …)every fixed stepbehaviour that belongs to one object

game.pause() freezes the simulation and keeps drawing. game.loop.timeScale = 0.3 is slow motion. game.tweens.to(target, { x: 5 }, { duration: 0.6 }) animates any numeric property.

Materials

MaterialWhat it is
BasicMaterialUnlit, or lit by the sun and ambient only. The cheapest; good for huge instanced fields.
StandardMaterialThe full light system: sun with shadows, point lights, fog. Colour texture, normal map, emissive map, vertex colours, palettes.
PBRMaterialThe same, lit from metallic and roughness. Reflects the scene's sky and ground colours.
ShaderMaterialYour own GLSL, with the engine's projection and lighting available as chunks.
GlowMaterialAn additive halo for a slightly larger copy of a mesh.
 
const bricks = await Texture.load("assets/bricks.png");
const bumps = await Texture.load("assets/bricks-normal.png");
const wall = new PBRMaterial({ map: bricks, normalMap: bumps, roughness: 0.8 });
const lamp = new StandardMaterial({ lit: false, color: [3, 2.2, 1] });      // brighter than white: it will bloom

After changing something that switches a shader feature on or off (adding a map, toggling lit), call material.invalidateProgram(). Changing colours and numbers needs nothing.

Light and shadow

The scene has one sun, a two-tone ambient (sky from above, ground from below), up to 16 point lights and optional fog. All of it is plain data on the Scene.

scene.sunDirection.set([0.5, -0.4, 0.76]);                     // pointing toward the sun
scene.sunColor.set([1, 0.92, 0.8]);
scene.pointLights.push({ position: [2, 0, 3], color: [2, 1, 0.5], radius: 8 });
scene.fogColor.set([0.6, 0.7, 0.9]); scene.fogDensity = 0.01;

scene.shadow = new ShadowMap({ center: [0, 0, 0], extent: [12, 12] });      // one box: a room, a board, a street
scene.shadow = new ShadowMap({ cascades: 3, distance: 150 });               // follows the camera: an open world

renderer.postfx = new PostFX(renderer, { ao: { enabled: true }, bloom: { intensity: 0.8 } });

With one fixed box, keep it as small as the play area: the same texture over less ground is sharper. With cascades the view is cut into slices by distance and each gets its own box, so shadows are sharp at your feet and still reach the horizon. See the open world example and switch between the two.

PostFX adds ambient occlusion, bloom, tone mapping ("aces" or "reinhard"), saturation, contrast, vignette and grain. Every setting can be changed while running through renderer.postfx.settings.

Models and animation

const asset = await loadGLTF("assets/models/robot.glb");        // { pbr: true } to use the file's metallic and roughness
const robot = game.add(asset.instantiate());                    // call again for another copy; geometry is shared
robot.animator.play("walk");
game.onRender((dt) => robot.animator.update(dt));
// later
robot.animator.play("wave", { fade: 0.3, loop: false });

The loader reads meshes, materials with their textures, one skin and its animations, morph targets and sparse accessors. Skeletons of up to 32 joints go to the GPU as uniforms; bigger ones (up to 256) travel in a float texture, which needs WebGL2 or the OES_texture_float extension. Draco and meshopt compression are not supported.

For a crowd, give each character its own Animator over the shared skeleton and clips, as the characters example does.

Input

The engine binds no keys of its own. A game names its actions and axes and reads those; keyboard, mouse, gamepad and on-screen controls all feed the same names.

input.bind("jump", ["Space", "GamepadA", "TouchA"]);
input.bindAxis("moveX", { negative: ["KeyA", "ArrowLeft"], positive: ["KeyD", "ArrowRight"], gamepad: "LeftX" });

const touch = new TouchControls(input);          // appears only on touch screens
touch.joystick({ x: "moveX", y: "moveY" });
touch.button({ code: "TouchA", label: "Jump" });

game.onUpdate((dt) => {
    if (input.wasPressed("jump")) player.jump();
    player.position[0] += input.axis("moveX") * speed * dt;
});

A tap that starts and ends between two steps is still reported by wasPressed in exactly one step, so quick presses are never lost. input.pointer has the position, drag deltas, wheel and pinch.

Collision and picking

// what is under the pointer?
const ray = camera.screenRay(input.pointer.x, input.pointer.y, canvas.clientWidth, canvas.clientHeight);
const hit = scene.raycast(ray)[0];               // nearest first: hit.entity, hit.distance, hit.point

// keep a player out of the walls, sliding along them
slideCircle(player.position, 0.4, walls);        // walls: [{ min: [x, y, z], max: [x, y, z] }, ...]

engine/Collision.js also has rays against spheres, boxes, planes and triangles, and overlap tests between spheres and boxes. There is no rigid-body physics; games so far have needed less than that.

Performance

  • Culling is automatic. A mesh whose bounding sphere is outside the camera's view is not drawn. Instanced, skinned and shader-displaced meshes have no reliable bounds, so give their entity a cullRadius if you want them skipped too.
  • Merge what never moves. Geometry.merge(parts) turns a street of buildings into one draw call. Merge per chunk, not per world, so chunks can be culled.
  • Instance what repeats. InstancedMesh draws thousands of copies in one call; only changed instances are re-uploaded.
  • Levels of detail. entity.lod = [{ distance: 0, mesh: fine }, { distance: 80, mesh: coarse }, { distance: 300, mesh: null }].
  • Quality presets. renderer.setQuality("low" | "medium" | "high" | "ultra") changes the resolution the scene is drawn at.
  • Measure. new DebugOverlay(game) and press the key under Esc: frame time, draw calls, what was culled, triangles.

Your own shaders

A ShaderMaterial is a vertex and a fragment shader in GLSL ES 1.00. Include the projection chunk and call projectLab(worldPosition) to reach the screen. Include the lighting chunk and call labLight(world, normal) to be lit, shadowed and fogged like everything else. The Renderer fills in every uniform those chunks declare.

import { ShaderMaterial, projectionChunk, lightingChunk } from "./engine/index.js";

const lava = new ShaderMaterial({
    name: "lava",
    uniforms: { u_heat: 1.5 },
    vertex: projectionChunk + `
        attribute vec3 a_position; attribute vec3 a_normal;
        uniform mat4 u_model; uniform float u_time;
        varying vec3 v_world; varying vec3 v_normal;
        void main() {
            vec4 world = u_model * vec4(a_position, 1.0);
            world.z += sin(world.x * 2.0 + u_time) * 0.1;
            v_world = world.xyz; v_normal = (u_model * vec4(a_normal, 0.0)).xyz;
            gl_Position = projectLab(world.xyz);
        }`,
    fragment: lightingChunk + `
        uniform float u_heat;
        varying vec3 v_world; varying vec3 v_normal;
        void main() {
            vec3 lit = vec3(0.3, 0.05, 0.02) * labLight(v_world, normalize(v_normal));
            gl_FragColor = vec4(labFog(lit, v_world) + vec3(1.0, 0.3, 0.05) * u_heat, 1.0);
        }`,
});

The custom shader example is a complete one.

Browser support

The engine targets WebGL2 and falls back to WebGL1 with extensions. On WebGL1 without depth textures, shadows and ambient occlusion switch themselves off and everything else still draws. The test page runs the suite in your own browser, on both kinds of context.
